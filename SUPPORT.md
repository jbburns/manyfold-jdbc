# Support

There is no support channel for this project. GitHub issues are the only place to ask questions
or report problems, and they are answered when time allows.

Before opening an issue, check the README for the URL syntax and the client setup walkthrough,
and search existing issues. A bug report needs the JDBC URL shape with credentials removed, the
backend driver versions, the client name and version, and the smallest SQL statement that shows
the problem. The issue form asks for each of these.
